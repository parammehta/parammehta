Currently a **Staff Software Engineer at Intuit**, on the design system behind QuickBooks, TurboTax, Credit Karma, and Mailchimp. Before that: identity and account experiences at Intuit, founding engineer on Rivian's Fleet Core, and marketplace + core components at Walmart.

**Full-stack** — GraphQL schemas and REST-to-GraphQL migrations, Node and Spring Boot services, event-driven systems on SQS/EventBridge/WebSockets, and AWS (Lambda, S3, CloudFront, SES).
